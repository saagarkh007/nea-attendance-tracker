# NEA Attendance & OT Tracker — Android PWA

Files:
- index.html — tracker app
- manifest.json — Android install metadata
- sw.js — offline app shell/service worker
- icons/ — app icons

The tracker stores local data in the browser/PWA and synchronizes attendance to the user's Google Apps Script backend.

Important: Do not put private attendance data into this GitHub repository. GitHub Pages hosts the app source publicly when using a public repository.
